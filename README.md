# Task 3 - Interactive Quiz & Joke API App

## Overview
This project was created for Task 3 of the ApexPlanet Web Development Internship Program. It demonstrates advanced CSS and JavaScript concepts through responsive design, an interactive quiz, and public API integration.

## Features
- Responsive layout using media queries
- Interactive multiple-choice quiz
- Dynamic score display
- Public API integration using fetch()
- Loading and error handling for API requests

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository
2. Open `index.html` in any modern browser
3. Use the quiz and click the joke button to fetch API data
